🗣️ 원어민 피드백 쉐도잉 연습장

수업에서 원어민이 교정해준 문장(x → o)이나 발음 지적을 받은 단어를 직접 입력하면, 듣기(TTS)와 따라 말하기(음성 인식)로 쉐도잉 연습을 할 수 있어요. (Chrome 브라우저 권장 — 마이크 권한 필요)

⚠️ 마이크 기능 안내

이 페이지가 https:// 주소가 아니라서, "따라 말하기"(마이크)는 브라우저 보안 정책상 작동하지 않거나, 마이크를 "허용"해도 계속 다시 물어볼 수 있어요(크롬이 file:// 페이지의 마이크 허용 상태를 저장하지 못하기 때문). 듣기(TTS)는 정상 작동합니다.
마이크 기능을 안정적으로 쓰려면 이 파일을 Netlify 같은 https 주소로 배포해서 사용해주세요(같이 보내드린 배포 가이드 참고).

① 문장 교정 쉐도잉

원어민 피드백을 한 번에 여러 개 붙여넣거나, 한 쌍씩 추가할 수 있어요. ⚠️ 아래 "한 번에 추가"는 기존 문장 목록을 지우고 새로 붙여넣은 내용으로만 교체합니다.
✨ 교정된 문장마다 비슷한 표현 4개를 자동으로 만들어드려요(AI 사용 · 로그인 불필요 · 100% 무료, AI 연결이 안 되면 사전 기반으로 자동 대체). 각 표현도 그대로 듣기/따라 말하기 연습이 가능합니다.
또는 한 쌍씩 직접 입력하기
아직 추가된 문장이 없어요.

② 단어 발음 연습장

발음이 틀렸다고 피드백받은 단어를 추가하고, 듣기 + 따라 말하기로 연습하세요. 여러 단어를 한 번에 붙여넣으면 단어마다 각각 카드가 만들어져요. ⚠️ 아래 "한 번에 추가"는 기존 단어 목록을 지우고 새로 붙여넣은 단어로만 교체합니다.
또는 한 단어씩 직접 입력하기
아직 추가된 단어가 없어요.

💾 전체 백업 (문장 + 단어)

이 페이지는 새로고침하면 목록이 사라져요. 아래 "내보내기"로 문장+단어 전체를 텍스트로 복사해 메모장 등에 저장해두었다가, 다음에 그 텍스트를 붙여넣고 "가져오기"를 누르면 그대로 복원됩니다.

📋 전체 요약 (복사용)

모든 문장의 교정 전/후, 문법 해석을 한 번에 모아서 볼 수 있어요. 아래 내용을 그대로 복사해서 노트나 문서에 붙여넣을 수 있습니다.
ⓘ 한글 번역은 구글 번역을 우선 사용하고(실패 시 MyMemory로 대체), 무료 API라 네트워크가 필요하며 드물게 번역이 표시되지 않을 수 있어요.
ⓘ 듣기(TTS)와 발음 인식(STT)은 브라우저의 Web Speech API를 사용하며, Chrome 데스크톱에서 가장 안정적으로 동작합니다.
ⓘ 문법 설명은 외부 API 없이 이 페이지 안에서 규칙 기반으로 자동 생성되는 근사치입니다.
