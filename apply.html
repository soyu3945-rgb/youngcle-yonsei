정규 수강 등록
  • 신청일 기준 최대 7일 이내 ~ 당일 2시간 전까지 수강 등록 가능
  • 수강 등록 후 수업 시작일 변경 불가
  • 수강권 별 횟수 일괄 등록 (예: 20회권은 20회 일괄 등록)
  • 1회 수강권은 자유예약으로만 신청 가능
수강 변경
  • 신청일 기준 최대 7일 이내, 수업 시작 2시간 전까지 가능
  • 변경 가능 항목: 시간, 요일, 강사, 과정
  • 수강 변경 후 취소 불가
수강 연기
  • 수업 시작 2시간 전까지 수강권 별 연기 횟수 내에서 신청 가능
  • 연기 시 마지막 수업 일이 다음 수업 일로 자동 연기
  • 연기 신청 후 취소 불가 / 연기 신청 채널: 홈페이지 및 담당자 카카오톡
대체강사 수강 연기
  • 강사 사정으로 대체 강사가 수업할 경우 문자로 사전 안내
  • 수업 진행을 원치 않으면 시작 1분 전까지 홈페이지, 담당자를 통해 직접 연기 가능
  • 대체 강사로 인한 연기 시에는 연기 횟수가 차감되지 않음
수강 중지
  • 1주 이상 수강이 불가할 때, 수업 시작 2시간 전까지 신청 가능
  • 중지 후 1주 이후부터 6개월 이내에 재등록 필수
  • 기한 내 미등록 시 등록된 잔여 횟수와 수강권 전체 소멸
자유예약
  • 사용 기간: 소강 등록일로부터 30일간(공휴일 포함) 유효
  • 과정 변경만 가능 (수강 연기, 시간 변경, 중지, 취소 모두 불가)
  • 홈페이지, 담당자를 통해서만 신청 가능 (유선, 카카오톡 신청 불가)
  • 수업 시작 1시간 전까지 신청 가능하며, 신청일 포함 익일 수업까지 예약 가능
